## 🛠 Feature Breakdown

### Feature 1 — Real-Time Chat
Direct messages and group chats powered by WebSockets.

### Feature 2 — Scalable Feeds
Fan-out on write vs. fan-out on read strategies.

### Feature 3 — User Graph
Friend requests, blocking, and mutual connections.

### Feature 4 — Notifications
In-app alerts, unread counts, and email digests.

### Feature 5 — Media Handling
Image and video uploads with CDN integration.

### Feature 6 — Security
Rate limiting, input validation, and secure auth.

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Socket disconnects** | Check Redis adapter |
| **Feed too slow** | Optimize fan-out |
| **Auth fails** | Check JWT secret |
| **Images missing** | Check S3 keys |
| **Chat not syncing** | Clear socket cache |
| **High CPU** | Reduce polling |
